# Skillora roadmap

## Phase 1 — Foundation
- [x] Design system (navy / deep blue / electric blue / cyan, Plus Jakarta Sans, light + dark)
- [x] i18n architecture (English default, Bahasa Indonesia), Intl formatting
- [x] Header, footer, navigation, responsive landing page
- [x] Marketplace browse page with working search, filters, sort, pagination (preview data)
- [ ] Enable Lovable Cloud; database schema + RLS for all core tables
- [ ] Authentication: sign up, login, password recovery, email verification, onboarding + role selection
- [ ] User profiles (photo, bio, skills, languages, location, verification status)

## Phase 2 — Marketplace
- [ ] Service creation (packages, FAQs, portfolio) and moderation status
- [ ] Service detail page, provider public profile
- [ ] Replace preview data with database reads; admin-managed categories

## Phase 3 — Orders
- [ ] Order creation, requirements, status, delivery, revisions, approval, cancellation, disputes
- [ ] Messaging with validated attachments and reporting
- [ ] Reviews from completed orders only

## Phase 4 — Dashboards
- [ ] Client, provider and admin dashboards; transaction records; audit logs

## Phase 5 — Monetization
- [ ] Commission from platform_settings; subscriptions; featured promotions
- [ ] Payment provider integration (server-verified, signed webhooks); payouts

## Phase 6 — International expansion
- [ ] More languages and currencies, regional config, advanced analytics, PWA
